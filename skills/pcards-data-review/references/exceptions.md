# Exception review

Prioritize large positive charges, then high-confidence missing links, conflicting destinations/years, unmatched credits and mixed-purpose invoices. Include all periods and cardholders relevant to the evidence. Don't present an automated scan as individual review of every transaction.

For each reported charge show ID, purchase date, amount, payer, merchant, exact notes, possible event/asset/person match, supporting IDs, contradictions, confidence and the specific missing document. Blank notes remain blank. Show gross charges and candidate credits separately until reconciled.

Useful next evidence is concrete: flight itinerary for session/date, hotel folio for stay/location, rental agreement for occupants, itemized invoice for mixed costs, fleet roster for unit/department. Don't repeatedly request permission for routine read-only comparisons already in scope.

Keep unresolved decisions in the ledger as holds, with rejected alternatives and a reopening condition. A later import should surface new notes/receipts for these records; it must not silently turn an unresolved item into a confirmed allocation. Report the number and dollars actually reviewed, separately from candidates scanned.
