# PCards / Penny Ping project workflows

For new or refreshed purchase data, merchant-note research, travel backfilling, unresolved-purchase reports, or publication of those changes, read and apply [the project data-review skill](skills/pcards-data-review/SKILL.md). Read only the references needed for the requested phase.

This workflow records reusable methods, not standing permission to publish new data. Preserve current source records, other contributors’ changes, and existing publication/privacy boundaries. A dirty or older local checkout is not the current live application.
